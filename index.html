Link options

Every card is a plain image link, so you can also write it by hand. Start from /api/card?platform=leetcode&username=YOUR_HANDLE and add any of these. Older /api/codeforces links keep working.

Option What it does
platform Which site: . Defaults to codeforces. Example: platform=atcoder
username Your handle on that platform. Not needed for the README extras.
type Which card: . Defaults to stats. Example: type=heatmap
theme One of . Defaults to light. Example: theme=dark
hide Comma separated parts to leave out. Each card lists what it has in the builder above. Example: hide=country,trend
bg_color and friends Your own colors as hex without the #: bg_color, title_color, text_color, muted_color, border_color. Example: bg_color=102a43&text_color=f0f4f8
hide_border Removes the outline around the card.
animate Set to false for a still card with no animation.
lines Typing intro only. The lines to type, separated by semicolons. Also color, size, width, speed, pause, center and background. Example: type=typing&lines=Hi, I'm Vishnu;I love DP
items Tech stack only. Your languages and tools, separated by commas. Also title. Example: type=stack&items=C++,Python,Git
type=combined The all platforms card. Give one handle per platform by its name, plus an optional title. Example: type=combined&codeforces=you&leetcode=you&atcoder=you
count and tz Upcoming contests only. How many to list, and the time zone for their start times. Example: type=upcoming&count=3&tz=Asia/Kolkata
type=banner Header banner. title, subtitle, shape (wave, slice or rounded), from and to for the gradient, text_color, height, and footer=true to flip it for the bottom of a README. Example: type=banner&title=Hi, I'm Vishnu&shape=slice
type=social One link badge for a "Connect with me" row. site is github, linkedin, x, email, website, youtube, instagram or discord, and label changes its text. Example: type=social&site=linkedin

Codeforces cards refresh every 30 minutes and upcoming contests every 10, so new results show up soon after they happen. Links made with earlier versions of this project still work.
